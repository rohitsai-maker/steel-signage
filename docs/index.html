Install on a new TV

  1. On the TV, install the free Downloader app from the Play Store / Amazon Appstore.
  2. Open Downloader and type this link:
  3. Install, then open Steel Signage. Nothing to type: it starts playing automatically.

Tips

  1. Order: files play in name order. Name them 01-welcome.jpg, 02-offer.mp4 and so on.
  2. Photo time: 10 seconds by default. For longer, end the name with seconds, like offer_20s.jpg.
  3. Videos play to the end. TVs update within about 1 minute of a change, and keep playing if the internet drops.
  4. Rotate the TVs: open the release, click Edit, change the first line to Orientation: portrait (or landscape, portrait-flipped, landscape-flipped) and click Update release. TVs rotate within about 1 minute.
  5. File size: anything up to 2 GB per file. On GitHub’s edit page, drop files in the box “Attach binaries by dropping them here”, not in the text box above it (that one is limited to 10 MB and the TVs ignore it).
  6. On a phone, if you don't see GitHub's Edit button, switch the browser to Desktop site.
Steel Signage · open source · content is public, so avoid private files
